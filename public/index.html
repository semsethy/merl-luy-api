Merl Luy Practice API

For practising 4 screens (Home, Activity, Add entry, Edit entry) in UIKit and SwiftUI, and for performance labs. Full docs are in README.md.

GET/api/summaryHome card
GET/api/transactionsmonth, kind, q, wallet_id, limit, offset
POST/api/transactionsAdd entry (client_id required)
GET · PATCH · DELETE/api/transactions/{id}Edit entry
GET/api/categories10 categories
GET/api/wallets3 wallets
GET/api/budgetsbudgets + spent
GET/api/perf/transactions?count=3000one big response (max 6000)
GET/api/perf/slow?ms=3000slow answer
